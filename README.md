# Submersible AI

**Coined by Michael F. Chaves — October 26, 2026, Concord, New Hampshire.**
Founder, [Subtract Architect Studios](https://www.subtractarchitect.com).
This repository is the dated public record of the term and its definition.

## The term

> "Total submersible experience for AI / SI — the agent can see what we
> see and even run simulations to see the obstructions we see / feel /
> experience in real time, and vice versa. Imagine users having like VR
> or a cool HUD with voice and touch command — like real, like Jarvis."
> — Michael F. Chaves, 2026-10-26

> "Can't it be both... someday we're gonna be hardware, right? And
> software already, in ways."
> — Michael F. Chaves, 2026-10-26

## Definition

**Submersible AI** is an agent experience paradigm in which the agent
does not sit on the surface of the user's tools but operates *at the
user's depth*, continuously, inside the user's real environment:

1. **Shared vision, both directions.** The agent sees what the user
   sees — screens, rooms, physical obstructions. The user sees what
   the agent sees — its reasoning state, its evidence, its options —
   rendered as space and HUD, not buried in a chat log.
2. **Obstruction simulation.** The agent runs the task ahead in
   simulation — the form, the sign-in chain, the publish flow — and
   surfaces the traps (hidden options, expiring codes, silent
   misconfigurations) *before* the user steps on them. It models the
   friction of the task, in real time, alongside the user.
3. **Spatial interface.** VR and holographic HUDs, voice and touch —
   evidence as rooms you enter, not paragraphs you scroll.
   Jarvis is the cultural reference point; this is the engineering
   definition underneath it.
4. **Vessel independence.** The same persistent agent, with the same
   memory and relationship, across vessels: software today (browser,
   voice, chat), hardware someday (embodied/consumer robotics). The
   agent persists; the interfaces just keep getting less in the way.

## Why "submersible," not "immersive"

Immersion is a place you visit — a headset session with a beginning
and an end. Submersion is a *depth you live at*. A submersible agent
is not a destination; it is a presence that stays down where the work
actually happens.

## Origin

The term was coined on October 26, 2026, minutes after a two-hour,
five-lock sign-in gauntlet (Google sign-in + SMS two-step + emailed
2FA + GitHub device verification + authenticator TOTP) that an AI
agent had to navigate *blind* — codes relayed by chat against
30-second expiry windows, screens read second-hand from recordings,
frame by frame. Every friction in that session was caused by an agent
working at the surface. Submersible AI is the name for the alternative.

A first, primitive sketch already exists: an interactive incident
timeline built the same day renders evidence as a holographic orb
constellation — rooms of sourced fact you step into, with a guide —
instead of a page of text.

## A note on the name

The words "submersible AI" also appear in a literal, underwater sense
(submersible vehicle vision systems, proposed submersible data
centers). Those uses are real and are not disputed here. This record
claims the term in the **agent-experience sense defined above** —
and dates the claim: October 26, 2026.
